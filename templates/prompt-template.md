# Master Prompt Template

```
[SUBJECT] {PRODUCT_TYPE}: {PRODUCT_DESCRIPTION — exact shape, size in mm, stone count, lettering}
[METAL] {METAL_BLOCK from references/metals.md}
[GEMS] {GEM_BLOCK from references/gems.md}
[SLOT] {SLOT_BLOCK from prompts/<slot>.md}
[STYLE] {STYLE_BLOCK from references/brand-style.md}
[FIDELITY] reproduce the reference product exactly — same shape, proportions, stone count, setting, chain, clasp and lettering; do not redesign
[OUTPUT] square 1:1, 2000x2000 px, photorealistic, sharp focus, sRGB
```

## Amazon negative block (append to EVERY prompt)
```
no text, no letters added to background, no watermark, no logo, no Amazon badges, no borders, no frames, no price, no other brands, no extra jewellery, no altered product design, no duplicate product, no distorted chain, no extra stones, no starburst flares, no blur, no cropping of product, no nudity, no suggestive pose
```
For **Main** additionally: `no model, no hand, no bust, no props, no shadow patches, no gradient, background pure white #FFFFFF`.

Text for infographics is added afterwards in Canva — never generated by AI.
