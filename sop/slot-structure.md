# Slot Structure (mirrors approved COS-JESUSNAMES set)

Benchmark files: `reference-sets/COS-JESUSNAMES/`. Each new SKU gets the same 10 deliverables, same order, same look.

| # | File name | Purpose | Text allowed | Model allowed |
|---|-----------|---------|-------------|---------------|
| Main | `<SKU>_MAIN.jpg` | Product alone on pure white, ≥85% fill | No | No |
| 2 | `<SKU>_S2.jpg` | **Dedicated macro detail** — pavé, facets, marks large and crisp (mandatory for any SKU with stones or fine detail) | Minimal callouts | No |
| 3 | `<SKU>_S3.jpg` | On-model (neck/ear/wrist/hand as relevant) | Optional short headline | Yes |
| 4 | `<SKU>_S4.jpg` | Size & scale — dimensions infographic | Yes (measurements) | Optional |
| 5 | `<SKU>_S5.jpg` | Features/benefits infographic (material, finish, closure) | Yes | No |
| 6 | `<SKU>_S6.jpg` | Lifestyle scene in brand mood | Optional | Yes |
| 7 | `<SKU>_S7.jpg` | Variants / colourways / styling options | Labels | Optional |
| 8 | `<SKU>_S8.jpg` | What's included / packaging (only what ships) | Labels | No |
| 9 | `<SKU>_S9.jpg` | Brand story / gift moment / care tips | Yes | Optional |
| EBC | `<SKU>_EBC_<module>.jpg` | A+ content modules | Yes | Yes |

Adapt a slot only when the product genuinely needs it (e.g. no variants → Slot 7 becomes second on-model angle). Record any change in the SKU sheet. Always check the benchmark image of the same slot before finalising.
