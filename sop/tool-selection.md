# Tool Selection (decide per slot before generating)

Prompts are tool-neutral. Use this guide, then note the choice in the SKU sheet.

| Slot | Best approach | Why |
|------|---------------|-----|
| Main | Real product photo, background removed (Canva/Photoshop/remove.bg), set to #FFFFFF | Highest accuracy, guaranteed compliance. Avoid pure AI for main. |
| 2 detail | Real macro photo, or AI upscale/relight with product reference | Must show true finish & stones |
| 3, 6 model/lifestyle | AI image tool with product image reference (e.g. Higgsfield, Gemini, Firefly) then composite real product if altered | Scenes/models are costly to shoot |
| 4, 5, 7, 8, 9 infographics | Canva (template locked to brand-style.md) using real cut-outs | Exact text, measurements & alignment |
| EBC/A+ | Canva at A+ module sizes | Precise dimensions & type |

Rules for any AI tool:
- Never let AI invent text on the product (names, engravings) — composite real lettering.
- Never let AI add text to the image — add text in Canva afterwards.
- Generate at ≥2000 px or upscale cleanly.
