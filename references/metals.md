## Rules
- Metal described in prompt, image text and Amazon listing must be identical. "Plate/Plated/Vermeil" must never be shortened to imply solid metal.
- Lighting for all metals: `soft diffused studio light, controlled highlights, no blown-out hot spots, true-to-life colour`.
- Shadow style follows `Shadow.psd` (soft contact shadow; on Main it must not create grey patches).
